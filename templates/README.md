# Reusable Engineering Templates

These templates implement the deliverable model in [`../lifecycle/03-deliverables-and-handover.md`](../lifecycle/03-deliverables-and-handover.md).

Use only the templates that carry real information for the project; combining files is allowed for small projects.

- [`requirements-and-traceability.md`](requirements-and-traceability.md) — DLV-01
- [`ui-screen-spec.md`](ui-screen-spec.md) — DLV-02
- [`system-design.md`](system-design.md) — DLV-03
- [`database-spec.md`](database-spec.md) — DLV-04
- source/config/migration/test files in the target repository — DLV-05
- [`installation-deployment-guide.md`](installation-deployment-guide.md) — DLV-06
- [`operation-acceptance-guide.md`](operation-acceptance-guide.md) — DLV-07

Principle: maintain changed truth, not ceremonial documents.
