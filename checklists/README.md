# Checklists

- Status: **draft**
- Baseline date: **2026-09-06**

Checklist는 사고를 대신하지 않습니다. 반복적으로 놓치기 쉬운 검토점을 빠르게 확인하는 보조 수단입니다.

예정 문서:

- `definition-of-ready.md`
- `requirement-review.md`
- `design-review.md`
- `implementation-review.md`
- `code-review.md`
- `test-review.md`
- `security-review.md`
- `release-readiness.md`
- `acceptance.md`
- `retrospective.md`

각 checklist 항목은 가능하면 관련 lifecycle/standard 문서로 연결하고, 단순히 체크박스 숫자를 늘리지 않습니다.
